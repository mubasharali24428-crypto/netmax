FAQ

Is this a scam?

No. 15 tools, 480 passing tests, MIT-licensed engine, published npm package. The only thing pending is Apple's $99 notarization — which the Founding License funds with a full refund guarantee.

Why $29 instead of $8/mo?

One-time for a utility is what the market pays. Subscriptions may come later — existing licenses keep 1.x updates free.

Windows / Linux / CI?

The MCP server (Node) and engine (Python + curl) run anywhere. The desktop GUI is macOS-only and will stay that way until sales prove demand.

License keys & piracy?

Gumroad issues a key on purchase; the app validates it offline. Piracy is trivially easy and we accept it — we'd rather lose keys to pirates than lose trust by overclaiming.
