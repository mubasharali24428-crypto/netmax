FAQ

Is this a scam / vaporware?

The product is real and shippable today: 14 tools, 190+ passing tests, MIT-licensed engine, published npm package (@netmax/mcp-server). The only thing pending is Apple's $99 notarization, which is what the Founding License funds — with a refund guarantee until it ships.

Why $29, not $8/mo?

We started with subscriptions in the docs, but one-time for a utility is what the market actually pays. Monthly plans may come later — existing licenses keep 1.x updates free.

Windows / Linux / CI?

The MCP server (Node) and engine (Python + curl) run anywhere. The desktop GUI is macOS-only and will stay that way until sales prove demand. We are not porting SwiftUI in 2026.

Mobile app?

Not a product. A phone companion might happen only if Pro adoption justifies it — and only as a companion, never a standalone pivot.

What's your privacy story?

Local-first. No telemetry, no accounts, no cloud. The app cannot upload your network data — there is no server component.

License keys?

Lemon Squeezy issues a key on purchase; the desktop app validates it offline. Piracy is possible and expected — we'd rather lose keys to pirates than lose trust by overclaiming.
