## 3. Design Tokens — Universal Patterns

### Spacing System (Universal)
- **Base unit**: 4px (42 apps) or 8px (28 apps)
- **Token scale** (used across 60+ apps):
  ```
  xxs: 2px  ·  xs: 4px  ·  sm: 8px  ·  md: 12px
  lg: 16px  ·  xl: 24px  ·  2xl: 32px  ·  3xl: 48px  ·  4xl: 64px
  ```
- **Section padding**: 48px–64px top/bottom on desktop
- **Card interior**: 24px padding
- **Button padding**: 12px vertical + 24px horizontal

### Typography Scale (Universal)
- **Display sizes**: 64px → 56px → 48px → 32px → 24px
- **Body sizes**: 18px → 16px → 14px
- **Caption**: 14px → 12px
- **Button label**: 16px–18px, weight 600–700
- **Display weight**: 400–900 (varies by brand; 500–600 is most common)
- **Body weight**: 400 (regular), 500 (medium), 600 (semibold)

## 5. Key Findings for Universal System Design

### What's Truly Universal
1. **Dark mode is non-negotiable** — 100% of apps support it
2. **Shadow system is mandatory** — 100% have elevation
3. **Rounded corners** — 99% use them
4. **4px base spacing unit** — dominant convention
5. **Inter font** — the de facto standard for body text (64–68 apps)
6. **Semantic color naming** — canvas/ink/primary/body/mute/border
7. **Two-face typography** — display + body font pairing
8. **Card-based layout** — 100% use card components
9. **Hero section** — 99% have a hero band
10. **Gradient accents** — 78% use gradients

### What Varies Significantly
1. **Primary accent color** — every brand has its own (terracotta, emerald, purple, blue, green, orange, yellow)
2. **Display typeface** — custom brand fonts vs. Inter vs. SF Pro
3. **Border radius preference** — 6px (Cal, Zapier) vs. 12px (most) vs. 24px (Wise, Airbnb)
4. **Background temperature** — cool gray vs. warm cream vs. true black
5. **Letter spacing** — varies from -2.4px to +1.5px
